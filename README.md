Your AI companion on Android. Version 1.3 with improvements and bug fixes.

## What is ZENO?

ZENO is an Android AI friend app — a virtual companion that:
- 💬 Talks to you naturally  
- 🧠 Understands context
- 🔧 Acts as your personal assistant

## What's New in v1.3

- Bug fixes and stability improvements
- Better conversation flow

## Download

Get the latest APK: [ZENO-v1.3.apk](./ZENO-v1.3.apk)

## Tech

- **Capacitor** (cross-platform native wrapper)
- **React + TypeScript** (UI)
- **Tailwind CSS** (styling)

## Install

1. Download the APK
2. Enable "Install from unknown sources" on your Android
3. Open the APK to install
